# IR reference

- `idual-rc-ii.irplus.xml` : 26 codes iDual RC II réellement testés par le propriétaire dans irplus.
- Format `WINLIRC_NEC1` ; mots d'affichage combinés `0x407Fxxxxxxxx`.
- Porteuse estimée ~38 kHz ; non mesurée sur l'exemplaire.
- Il faut confirmer la traduction des mots NEC1 en durées électriques avant de déclarer l'APK opérationnelle.
